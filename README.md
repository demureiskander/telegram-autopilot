# 🤖 telegram-autopilot — cloud

🇷🇺 Русский · 🇬🇧 [English](README.en.md)

> **Попробуйте прямо сейчас → [@RavelioBot](https://t.me/RavelioBot)**

Персональный AI-ассистент встроенный в ваш Telegram профиль.  
Читает входящие сообщения и отвечает от вашего имени — пока вы заняты, в дороге или просто хотите делегировать рутину.

Подключается через официальную функцию Telegram **«Автоматизация чатов»** — никаких серых схем, только официальный Bot API.

## ✨ Возможности

- 💬 **Отвечает в вашем стиле** — вы задаёте тон, фразы и характер через системный промпт
- 🔘 **On/Off одной кнопкой** — включайте когда заняты, выключайте когда вернулись
- 📝 **Два типа заметок** — ваши заметки о контакте + заметки ИИ которые обновляются автоматически
- 🧠 **Умный контекст** — ассистент знает кто пишет, сколько раз уже общались, что известно о собеседнике
- 🎭 **Определение тональности** — адаптируется между формальным и неформальным стилем
- 📊 **Панель управления** — статистика, история чатов, редактор промпта, выбор модели
- 🔁 **Автопереключение моделей** — если основная модель недоступна, переходит на резервную
- 🔌 **Работает с любым OpenAI-совместимым API** — OpenRouter, DeepSeek, NeuroAPI и другие

## 🚀 Быстрый старт (self-hosted cloud)

### Требования

- Python 3.12
- Telegram бот с включённым Business Mode
- API ключ от любого OpenAI-совместимого провайдера
- Сервер или Railway для хостинга

### 1 — Клонируйте репозиторий

```bash
git clone https://github.com/demureiskander/telegram-autopilot.git
cd telegram-autopilot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2 — Создайте бота

1. [@BotFather](https://t.me/BotFather) → `/newbot`
2. `/mybots` → Bot Settings → **Business Mode** → Turn on
3. Скопируйте токен

### 3 — Настройте .env

```bash
cp .env.example .env
```

```env
BOT_TOKEN=токен_из_BotFather
OWNER_ID=ваш_telegram_id        # получите через @userinfobot
LLM_API_KEY=ключ_от_провайдера
LLM_BASE_URL=https://openrouter.ai/api/v1/chat/completions
LLM_MODEL=deepseek/deepseek-chat-v3-0324:free
DB_PATH=bot.db
MAX_HISTORY=12
BOT_USERNAME=@YourBotUsername    # замените на юзернейм своего бота
```

> ⚠️ `OWNER_ID` даёт доступ к команде `/owneradmin` — только для вас как владельца.

### 4 — Замените @YourBotUsername

```bash
grep -rn "@YourBotUsername" handlers/
```

### 5 — Запустите

```bash
python bot.py
```

## ☁️ Деплой на Railway

1. Запушьте репозиторий на GitHub
2. [railway.app](https://railway.app) → New Project → Deploy from GitHub
3. Добавьте все переменные из `.env` в раздел **Variables**
4. Добавьте **Volume** → mount path `/app/data`
5. Добавьте переменную `DB_PATH=/app/data/bot.db`

Railway деплоит автоматически при каждом пуше в `main`.

## 🛠 Панель управления

Команда `/admin` открывает личную панель:

| Кнопка | Что делает |
|---|---|
| ✅/⏸ Включить/выключить | Включает или выключает автоответ |
| 📊 Статистика | Сообщений за день, уникальных чатов |
| 💬 Чаты | Список переписок с заметками и историей |
| ✏️ Промпт | Просмотр и редактирование системного промпта |
| 🤖 Модель | Выбор LLM модели |
| 🗑 История | Очистка истории чатов |
| 💳 Подписка | Тарифы и оплата |

### Быстрые команды

| Команда | Действие |
|---|---|
| `/start` | Начать / вернуться к настройке |
| `/admin` | Открыть панель управления |
| `/on` | Включить автоответ |
| `/off` | Выключить автоответ |
| `/status` | Текущий статус |
| `/help` | Инструкция по подключению |

## 👑 Панель владельца

Команда `/owneradmin` — только для `OWNER_ID`:

- **Статистика** — воронка онбординга, подписки по планам, прирост
- **Активность** — DAU/WAU/MAU, сообщения по дням, ошибки LLM, использование моделей
- **Финансы** — Stars, Stars→USD, транзакции по планам
- **Пользователи** — список с пагинацией
- **База данных** — экспорт `.db.gz`
- **Очистка** — удаление events старше 30/90 дней

```
/banuser ID      — заблокировать пользователя
/unbanuser ID    — разблокировать
/deleteuser ID   — удалить все данные пользователя
```

## 🧠 Как работает контекст

Каждый запрос к LLM содержит три блока:

```
=== РОЛЬ АССИСТЕНТА ===
AI-ассистент встроенный в Telegram профиль пользователя...

=== О ВЛАДЕЛЬЦЕ ПРОФИЛЯ ===
[системный промпт который настроил пользователь]

=== КТО СЕЙЧАС ПИШЕТ ===
Имя: ...  Username: @...
[заметка пользователя + заметка ИИ если есть]
[первое сообщение / сообщение #N]
```

### Автоматические заметки

После каждого сообщения фоновая задача анализирует диалог и если узнала что-то новое о собеседнике — обновляет заметку автоматически.

## 🔒 Приватность

Логи содержат только метаданные — user_id, chat_id, модель, время. Текст сообщений **не логируется** на уровне сервера.
